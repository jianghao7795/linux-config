# LazyVim 诊断信息自动换行设计

## 目标

让 LSP 诊断错误信息在代码旁虚拟文本和诊断浮窗中都保留完整内容，并由界面自动换行，避免当前配置造成的单行合并和 120 字符截断。

## 方案

继续使用 `lua/plugins/vus.lua` 中现有的 `nvim-lspconfig` 诊断配置：

- 虚拟文本格式化函数不再替换换行符，也不再按字符数截断。
- 诊断浮窗开启 `wrap`，保留动态宽度和高度限制，使长文本在窗口内换行并完整显示。
- 保留诊断码 `7016` 的过滤行为，以及现有浮窗边框、来源和尺寸配置。

## 行为与边界

诊断内容本身不被修改或裁剪。浮窗仍受屏幕尺寸限制，内容通过换行适应可用宽度；虚拟文本继续显示在诊断行旁，由 Neovim 的窗口布局处理可视区域。该改动不影响 LSP 服务启动、服务器设置或其他插件配置。

## 验证

- 使用 Neovim 无界面模式加载配置，确认 Lua 配置可正常解析。
- 检查最终差异，确认只包含诊断显示配置和本设计文档，不覆盖用户已有的 `lazy-lock.json` 修改。
